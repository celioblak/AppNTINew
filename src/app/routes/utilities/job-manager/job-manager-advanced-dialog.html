build Ações de Gerenciamento

Ações que afetam todo o scheduler

restart_alt Reiniciar Scheduler Reinicia o scheduler quando ele travar

Esta ação irá parar e reiniciar completamente o scheduler. Jobs em execução serão interrompidos.

info Apenas esta instância será reiniciada (ambiente cluster)
cleaning_services Limpar Jobs Órfãos Remove jobs que estão no scheduler mas não no banco

Remove jobs que estão registrados no scheduler mas não existem no banco de dados (jobs órfãos).

info Será executado em todas as instâncias do cluster
block Cancelar Todos os Jobs Impide triggers futuros, mas não interrompe jobs em execução

Cancela todos os triggers futuros. Jobs atualmente em execução serão concluídos normalmente.

info Afeta todas as instâncias do cluster (estado compartilhado)
replay Recriar Todos os Jobs Recria todos os jobs do banco no scheduler

Recria todos os jobs registrados no banco de dados no scheduler. Útil após problemas de sincronização.

info Será executado apenas nesta instância

dns Ações de Cluster (Todas as Instâncias)

Estas ações afetarão TODAS as instâncias do cluster

restart_alt Reiniciar TODAS as Instâncias Reinicia o scheduler em todos os nós do cluster

Esta ação enviará um comando para reiniciar o scheduler em TODAS as instâncias do cluster simultaneamente.

warning ATENÇÃO: Interromperá jobs em execução em TODOS os nós
replay Recriar Jobs em TODAS as Instâncias Sincroniza e recria jobs em todos os nós

Sincroniza todos os nós do cluster com o banco de dados e recria todos os jobs em cada instância.

block Cancelar TODOS os Jobs (Cluster) Pausa todos os triggers em todo o cluster

Pausa todos os triggers em TODAS as instâncias do cluster. O estado é compartilhado via banco de dados.

warning

Atenção: Estas ações afetam todo o scheduler e podem interromper a execução de jobs. Use com cautela. Em ambiente cluster, algumas ações afetam apenas a instância local, enquanto outras afetam todo o cluster.
